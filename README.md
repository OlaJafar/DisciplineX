# DisciplineX

## Overview

DisciplineX is a web-based mentorship platform that connects students with mentors in a structured learning environment.

The platform allows students to find mentors, book sessions, and follow clear learning plans, while mentors can manage their teaching, track student progress, and communicate easily.

---

## Main Features

* User accounts (Student / Mentor)
* Mentor search and filtering
* Session booking (free & paid)
* Personalized learning roadmaps
* Progress tracking (streaks, charts, etc.)
* Ticket-based communication system
* Reviews and ratings

---

## Tech Stack

**Frontend:** React.js, Redux, Material UI
**Backend:** ASP.NET
**Database:** SQL Server, Redis
**Other:** Stripe API, Socket.IO, Daily.co
